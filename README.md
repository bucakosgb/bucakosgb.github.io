# Bucak OSGB sitesi

Canlı adres: https://bucakosgb.github.io/

- `index.html`: Sayfa metinleri, hizmetler ve iletişim bilgileri.
- `styles.css`: Görünüm ve mobil uyumluluk.
- `script.js`: Menü etkileşimleri.
- PNG ve SVG dosyaları: Logo ve referans görselleri.

`main` dalına yapılan değişiklikler GitHub Pages ile otomatik yayımlanır. Değişikliklerin canlıya yansıması birkaç dakika sürebilir.
