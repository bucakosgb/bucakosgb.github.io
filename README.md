# Bucak OSGB sitesi

Canlı adres: https://bucakosgb.github.io/

- `index.html`: Sayfa metinleri, hizmetler, iletişim bilgileri ve sıkça sorulan sorular.
- `styles.css`: Görünüm, iş güvenliği uzmanı illüstrasyonu, risk matrisi ve mobil uyumluluk.
- `script.js`: Menü etkileşimleri ve fareyi takip eden uzman animasyonu.
- PNG ve SVG dosyaları: Logo ve referans görselleri.

`main` dalına yapılan değişiklikler GitHub Pages ile otomatik yayımlanır. Değişikliklerin canlıya yansıması birkaç dakika sürebilir.
